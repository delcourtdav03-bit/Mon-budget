MON BUDGET V24.7.4 — RECHERCHE GLOBALE

Objectif :
Retrouver rapidement une information après plusieurs mois d'utilisation.

Accessible via :
- icône recherche dans l'en-tête
- Ctrl+K / Cmd+K sur ordinateur

La recherche couvre :
- dépenses
- revenus
- transferts
- dépenses récurrentes
- mouvements d'épargne
- enveloppes d'épargne
- objectifs
- budgets de catégories

Exemples :
- Ikea
- Courses
- 49
- 49,00
- septembre
- Loyer
- vacances

La recherche comprend aussi :
- montants avec point ou virgule
- catégories renommées
- noms des comptes
- tags
- mois et dates en français

Navigation :
- une opération ouvre Activité au bon mois et au bon compte
- un récurrent ouvre Prévoir > Dépenses récurrentes
- une épargne ouvre le module d'épargne
- une enveloppe ouvre Mes enveloppes
- un objectif ouvre Mes objectifs
- un budget ouvre Réglages > Budget

Aucune donnée n'est modifiée par une recherche.
Aucune logique cloud ou financière modifiée.
