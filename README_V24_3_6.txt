MON BUDGET V24.3.6 — ÉPARGNE LIBRE MODULABLE

Nouveau :
- l'épargne libre n'est plus calculée depuis les anciens historiques
- nouveau solde réel indépendant par compte
- + Ajouter
- − Retirer
- Ajuster le solde exact
- derniers mouvements visibles
- les nouveaux ajouts vers "Épargne libre" mettent à jour ce solde
- modifier/supprimer une nouvelle entrée libre ajuste le solde
- supprimer une enveloppe transfère son solde vers l'épargne libre
- les anciennes entrées restent dans l'historique sans gonfler automatiquement le solde libre

Migration :
- pour un utilisateur venant de V24.3.5, le nouveau solde libre commence à 0 € par défaut.
- utilise "Ajuster" pour indiquer le montant réellement détenu.
