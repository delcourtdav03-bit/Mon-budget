MON BUDGET V24.5.9 — SIMPLIFICATION UX

Objectif :
Réduire la densité de l'accueil sans supprimer les fonctions.

Accueil simplifié :
- compte + mois fusionnés dans une barre compacte
- grande carte principale conserve disponible / revenus / dépenses / épargne
- score de santé budget intégré directement à la carte principale
- centre d'actions réduit aux 2 priorités les plus utiles
- prévisions : seulement budget sûr/jour + fin de mois probable visibles
- détails de prévision accessibles à la demande
- assistant compact ; conversation dépliée seulement lorsqu'elle est utilisée
- analyses secondaires regroupées dans « Analyse détaillée »

Modules déplacés :
- Coach hebdomadaire → Stats
- Pilotage du mois + épargne → Prévoir
- Automatisation intelligente → Réglages

Couleurs intelligentes :
Score santé budget (plus haut = mieux)
- 0–39 : rouge
- 40–54 : orange/rouge
- 55–69 : ambre
- 70–84 : vert doux
- 85–100 : vert franc

Ratio dépenses / revenus (inverse : plus haut = plus risqué)
- <65 % : vert
- 65–79 % : vert/ambre
- 80–94 % : orange
- 95 %+ : rouge

Exemple : un score de 62 % apparaît maintenant en ambre, pas en rouge vif.

Aucun changement à Supabase / déconnexion.
