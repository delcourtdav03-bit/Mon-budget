MON BUDGET V24.4.5 — LOCAL FIRST

Changement principal :
- aucun écran de connexion ne bloque l'ouverture de l'application ;
- l'application démarre toujours en mode local ;
- les comptes Supabase sont optionnels ;
- création de compte / connexion uniquement dans Réglages ;
- si le cloud échoue, l'application reste utilisable ;
- une déconnexion ne vide plus l'application et ne bloque plus l'utilisateur ;
- le bouton de l'accueil mène à Compte / Cloud.

Philosophie :
Local d'abord, cloud ensuite.
Le cloud sert à sauvegarder/synchroniser, pas à autoriser l'accès à Mon Budget.
