MON BUDGET V24.7.2 — NOUVEAU MOIS INTELLIGENT

Objectif :
Éviter de reconfigurer manuellement le budget à chaque nouveau mois.

Fonctionnement :
- dans Prévoir, une carte propose de préparer le mois suivant
- le plan du mois courant sert de base
- revenu prévu, charges fixes prévues et objectif d'épargne sont modifiables avant validation
- le mois préparé s'ouvre directement après validation

Important :
- aucune dépense réelle n'est copiée
- aucun revenu réellement reçu n'est copié
- aucun transfert n'est copié
- aucun mouvement d'épargne réalisé n'est copié

Ce qui continue déjà automatiquement dans l'app :
- budgets par catégorie
- dépenses récurrentes
- comptes
- règles automatiques
- enveloppes d'épargne

Passage réel au nouveau mois :
- si le mois courant n'a pas encore de plan mais que le mois précédent en possède un,
  un petit bandeau apparaît sur l'accueil
- l'utilisateur peut préparer le mois ou masquer le rappel pour ce mois

Sécurité :
- une sauvegarde locale de récupération est créée avant remplacement/création du plan
- le système ne duplique pas les opérations

Aucun changement au cloud/Supabase.
