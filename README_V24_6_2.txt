MON BUDGET V24.6.2 — RÉGLAGES SIMPLIFIÉS

Objectif :
Rendre l'onglet Réglages beaucoup plus lisible sans retirer de fonctionnalité.

Nouvelle organisation :
1. Compte & Cloud
   - connexion / création de compte
   - synchronisation
   - envoi / récupération cloud
   - configuration Supabase rangée dans « Options techniques »

2. Budget
   - Plan du mois
   - Budgets par catégorie
   - Catégories personnalisées
   - Modèles rapides

3. Automatisation
   - Suggestions intelligentes
   - Mémoire des commerçants
   - Règles automatiques

4. Données & sauvegarde
   - Santé des données
   - Export / import JSON
   - Import Excel / CSV
   - Récupération locale
   - Zone dangereuse repliée

5. Préférences
   - Personnalisation de l'accueil
   - Notifications système

UX :
- cinq entrées compactes en haut des Réglages
- accordéons repliables
- une seule section ouverte par défaut
- compte/cloud immédiatement accessible depuis l'accueil
- anciennes commandes de connexion conservées en arrière-plan pour compatibilité JS

Aucune fonction supprimée.
Aucune modification du comportement Supabase / déconnexion.
