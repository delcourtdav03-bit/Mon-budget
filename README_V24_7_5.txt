MON BUDGET V24.7.5 — SAISIE EXPRESS INTELLIGENTE

But :
Encoder une dépense quotidienne en quelques secondes.

Nouveau flux :
1. montant
2. commerçant / nom
3. catégorie + type déjà proposés si Mon Budget reconnaît l'habitude
4. valider

Habitudes :
- jusqu'à 6 commerçants récents/fréquents apparaissent comme raccourcis
- toucher un raccourci préremplit le nom, la catégorie et le type
- le montant habituel sert de repère visuel, mais n'est jamais ajouté automatiquement

Reconnaissance :
- utilise le moteur d'habitudes déjà existant
- les règles manuelles ont priorité
- un historique suffisamment fiable peut présélectionner catégorie + fixe/variable
- une catégorie modifiée manuellement dans la fenêtre n'est pas écrasée ensuite

Clavier :
- Entrée après le montant → commerçant
- Entrée après le commerçant → enregistrer

Plus d'options :
- les valeurs saisies dans la fenêtre express sont transférées vers le formulaire complet

Sécurité :
- aucun montant n'est deviné puis enregistré silencieusement
- montant > 0 obligatoire
- aucune connexion bancaire
- aucune logique financière mensuelle modifiée
