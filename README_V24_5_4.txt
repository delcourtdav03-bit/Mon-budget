MON BUDGET V24.5.4 — AUTOMATISATION INTELLIGENTE

Nouveau :
- mémoire locale des commerçants à partir de l'historique
- reconnaissance approximative des noms similaires (ex. variantes d'un même commerçant)
- suggestion automatique catégorie / nature / périmètre
- montant habituel calculé par médiane
- aide directement dans le formulaire Dépense
- aide intelligente dans le scanner de ticket
- auto-classement scanner uniquement en cas de confiance suffisante
- détection améliorée des dépenses récurrentes
- score de confiance pour les récurrents probables
- proposition de créer une règle automatique quand plusieurs opérations sont classées pareil
- bouton Ignorer pour masquer une suggestion
- écran Réglages > Mémoire intelligente
- compteurs : commerçants appris / récurrents détectés / règles actives

Important :
- aucune dépense n'est créée automatiquement
- aucune règle/récurrence n'est ajoutée sans validation
- l'apprentissage reste dans les données de l'application
- aucun changement à Supabase / déconnexion
